# Lesson plans

Every PDF in this folder is searchable on the Lesson Plan Finder.

**To add a plan:** open the subject folder, then the grade folder → **Add file → Upload files** → drag in your PDFs → **Commit changes**. It's searchable about a minute later.

Folders go `subject/grade/` (for example `math/grade-3/`). For a new grade, drag in a folder named like `grade-7` with the PDFs inside it.

More detail: [the full guide](../README.md#adding-a-lesson-plan).
